# 上手宣传片 · 帧制作规格（给帧 worker）

项目根：`videos/gonggong-onboarding/`（HyperFrames，1920×1080，30fps）。整片《招一位 AI 新同事》：面向**不懂技术的同事**（产品、运营、设计、数据）。视觉沿用讲解片浅色 Pane 风格（macOS + 飞书 IM），强调蓝 `#0a7cff`，朱红 `#d23b2a` 只用于圈注、印章、痛点。

## 你要做什么

只改分配给你的 `compositions/fNN.html`（现在是占位文件）。**不要改** `index.html`、`assets/shared.*`、`timeline.json`、其他帧、音频、STORYBOARD.md。

**必读样板**：`../gonggong-explainer/compositions/c1.html`（讲解片定稿章节，结构、类名、GG 动作调用方式照它来；但本片**没有关卡卡**，不要用 `.lv` / `GG.level`）。`assets/shared.css`（全局组件类）和 `assets/shared.js`（`window.GG` 动作库）由 index 统一加载，帧里直接用。看 `frame.md` 了解配色与组件。

## 硬性约定

- 子合成格式：`<template>` 内放 `<style>`、根 div、`<script>`。根 `id="fNN-root" data-composition-id="fNN" data-width="1920" data-height="1080"`；时间轴 `window.__timelines['fNN'] = tl`（`gsap.timeline({ paused: true })`）。
- 所有 id 以 `fNN-` 开头；帧 CSS 全部写在 `#fNN-root …` 或 `#fNN-xxx` 选择器下，不写裸类名规则。
- 时间全部是**帧本地时间**（0 = 本帧开始）。台词本地起止见下表。正文元素在 0–0.6s 内开始进场（帧开头别空着）；最后 0.35s 内把主要内容淡出（opacity→0 + 轻微 y/scale），不要对 `#fNN-root` 本身做动画。
- 版式：左舞台 x 80–1200、y 130–940 放演示；右栏 `.col`（x 1250–1860）放 `.kick` + `.ttl` + `.kps` 要点（2–3 条）——**步骤帧（f05–f09）必须用右栏**，其他帧可全屏自由构图。**y 960 以下留给字幕**；f05–f09 左上 y 30–100 是步骤 HUD（index 提供），别压。
- 音效约定（统一合成，你的动画要对齐）：每条**解说 [N]** 台词开始前 0.15s 有「嗖」→ 对应演示内容此刻进场；台词开始 +0.6s 有「叮」→ 对应要点（`GG.kp`）或关键标注此刻弹出。角色台词 [G]/[F] 开始前 0.2s 有「啵嘤」→ 角色此刻用 `GG.cameo` 冒出。特殊音效见各帧「特效音」，必须在那个时刻做出对应画面。
- 动画只用 GSAP `fromTo`/`to`/`set`，确定性；禁止 `repeat: -1`、`Math.random`、`Date`。不要给帧内元素加 `clip` 类。
- 字体只用 `system-ui, -apple-system, sans-serif`（不要写 PingFang 等未声明字体，lint 会报错）。渲染时字体度量比预览略宽：单行标题/标签留 ≥10% 余量，或 `white-space: nowrap` 并控制宽度。中文正文 ≥ 24px，标题 56–128px。
- **受众零技术背景**：画面上不出现 git、diff、分支、命令行、终端、token、代码等字样；不要出现 `todo-app`、`.js` 文件名。截图里难免带研发内容时，只露出要讲的那块（推近/裁切），或用白色面板盖住无关部分。
- 术语：Bot、机器、群、Bot 主人、审批、预览、公开链接；产品名「共工空间」；网址 `https://ai.ludoukj.com`。「艾特」在画面上写成 `@`。
- 统一示例故事：运营**小美**在「**双十一活动群**」里让 Bot「**活动页助手**」把活动页按钮改成蓝色、文案换成「立即抢购」。群成员：小美（运营，头像色 #e0533a）、老周（产品，#c46a2b）、阿杰（研发，#3a6fd8）。Bot 形象用 `assets/cast/steps-*.svg`（小步）。
- 功能描述严格按本文件，不要自行发挥新功能。

## GG 动作库（assets/shared.js）

- `GG.head(tl, '#fNN-col', t)` 右栏标题进场。`GG.kp(tl, sel, t)` 要点弹出（`.kp > .no + span`）。
- `GG.enter(tl, sel, t, from='right'|'left'|'up'|'down')` / `GG.leave(tl, sel, t)` 卡片进出。
- 截图卡：`.screen > .bar(i,i,i,span) + .vp > .zoomer > img + svg.ring…`。img 用显示尺寸写死 width/height（= 原图尺寸 × S），`.vp` 高度 = 原图高 × S。`GG.ring(sel, S, [x,y,w,h], pad)` 用**原图像素**圈区域；`GG.draw(tl, ringSel, t, dur)` 画圈；`GG.focus(tl, zoomerSel, S, [x,y,w,h], vpW, vpH, t)` 推近，`GG.unfocus` 拉回。`.note` 朱红小标签做圈注说明。
- `GG.cameo(tl, sel, tIn, tOut)` 角色从下方冒出说话（`.cameo > img + .say`，`.say.l` 气泡朝左）。cameo 的 `top` 设在 640–720。tIn = 台词开始时间，tOut = 台词结束 + 0.2。
- 组件类：`.panel`（白色圆角面板做仿真界面）、`.msg/.av/.who/.bb/.me/.at`（聊天气泡）、`.chip(.g/.r/.y/.k)`、`.note`。

## 自检（交付前必做）

1. `cd videos/gonggong-onboarding && npx hyperframes@0.8.148 lint` —— 你的帧不能有 error（index 里 music.wav/sfx.wav 缺失的报错忽略）。
2. 用 `npx hyperframes@0.8.148 snapshot --at <全局秒,...>` 在你帧的 4–6 个关键时刻截图（全局秒 = 帧 start + 本地秒，见每帧标题），用 Read 看 `snapshots/` 下的图：检查文字溢出、重叠、压字幕区、元素没出现/没退场。有问题就修，再截。
3. 回报：改了哪个文件、关键时刻截图结论、任何偏离本规格的地方。
