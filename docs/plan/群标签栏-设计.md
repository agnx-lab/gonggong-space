# 群标签栏（设计）

参考飞书群顶部标签：群头部下方横排一行标签，用来快速跳到常用页面。姜维川 2026-10-22 确定以下范围：

- 一期做四类标签：链接、知识库条目、工作区文件、固定入口。
- 给 Bot 提供 MCP 工具。
- 所有群成员都能增删改和排序。
- 标签全群共享，存在服务端，实时同步。

## 交互

- 位置：放在 `ChatHeader` 下方，单独一行，高 36px。第一个是固定的「消息」标签，后面是群标签，最后是「＋」。放不下的部分收进「更多 ▾」。
- 点击标签：在右侧工作台打开对应的 tab，打开时工作台自动展开。按住 ⌘ 点击，或者右键选「在新标签页打开」，会交给浏览器（桌面端交给系统浏览器）。
- 右键菜单：在新标签页打开、复制链接、重命名、删除。标签可以拖拽排序。
- 「＋」弹窗的第一个页签是「链接」：输入 URL 后服务端抓取标题和图标，标题可以手动改。另外三个页签分别是「知识库」「文件」「入口」，从下拉里选，标题默认取对象自己的名字。
- 对象失效时（知识库条目被删、Bot 已移出群），标签置灰并显示「已失效」，可以直接删掉。文件是否存在不在列表里检查，打开时由文件视图提示。

## 标签类型

| kind | 存储 | 打开方式 |
|---|---|---|
| `link` | url、favicon、embeddable | 能嵌入时用工作台 `web` tab（新增 `url` 来源）打开；不能嵌入时直接新开浏览器标签 |
| `knowledge` | knowledgeId | 工作台新增 `knowledge` tab，只读渲染 markdown，可以跳到编辑 |
| `file` | botId + path | 复用现有工作台 `file` tab |
| `entry` | entry：`notice` / `pins` / `schedules` / `git-log` | 打开对应的 Inspector 子页或工作台 tab |

## 服务端

- 新建 `group_tabs` 表，字段：id、groupId、kind、title、target(jsonb)、position、createdBy、createdAt、updatedAt。每个群最多 30 个标签。需要迁移。
- 新建 `modules/group-tabs`，提供以下接口：
  - `GET /groups/:id/tabs`
  - `POST` / `PATCH` / `DELETE`
  - `PUT /groups/:id/tabs/order`
- 每次改动都通过实时事件 `group.tabs` 广播，并发一条群事件「{name} 添加了标签 {title}」。
- 抓取链接元数据：`POST /link-meta {url}`。只允许 http/https；DNS 解析后拒绝内网、回环、链路本地地址，防 SSRF。超时 5s，最多读 512KB。从页面解析 `<title>`、`og:title` 和 favicon。根据 `X-Frame-Options` 与 CSP `frame-ancestors` 判断 `embeddable`。内网地址取不到元数据，标题默认用主机名，照样能加。
- 嵌入第三方页面时，iframe 加 `sandbox="allow-scripts allow-same-origin allow-forms allow-popups"` 和 `referrerpolicy="no-referrer"`。第三方页面不同源，拿不到我们的 cookie。

## Bot 工具

- 新增两个工具 `tab_create {kind, title?, url|knowledge_id|path}` 和 `tab_list`，接入 `packages/protocol/src/tools.ts` 与 `agent-tools`。daemon 编译时内嵌工具清单，旧版 daemon 上的 Bot 要等下次发版才看得到这两个工具。
- 典型场景：Bot 写完报告或文档后，顺手把它钉到群顶部。
- 不提供删除工具，删除只能由人来做。

## 后续可扩展（本期不做）

- HTML 页面标签：内容存服务端，用 `CSP sandbox` 的方式下发。
- 置顶预览：预览关闭后标签失效。
- 飞书文档识别：给飞书文档链接配专属图标。
- 个人隐藏某个标签。
