# v0.3.7

这一版把手动 Git 做成了可用的日常流程：Git 状态实时，提交时可以只选部分文件，提交历史和文件对比里能直接看差异；定时任务改为每次在独立的新会话中运行；`client_release_publish` 支持一次上传整个发布目录，只需审批一次。

This release makes manual Git usable day to day: the Git status stays current, commits can take only some of the files, and the history and file compare show diffs. Scheduled tasks now run in a fresh session every time. `client_release_publish` can upload a whole release directory in one approval.

## 亮点 / Highlights

- **Git 状态实时 / Live Git status** —— 打开 Git 菜单、分支下拉或提交对话框、回到窗口时刷新状态；菜单新增「获取远程更新」，拉取与推送显示 ↓N / ↑N，没有改动时「提交…」置灰。
  The status refreshes when the Git menu, the branch picker or the commit dialog opens, and when the window regains focus. The menu adds "Fetch remote updates"; pull and push show ↓N / ↑N, and "Commit…" is disabled without changes.
- **只提交选中的文件 / Commit selected files** —— 提交对话框列出所有改动，可逐个勾选、全选或取消，支持 ⌘/Ctrl+Enter 提交；没选中的改动保持未提交。成员申请的提交同样只包含申请时选中的文件。
  The commit dialog lists every change with checkboxes, select-all, and ⌘/Ctrl+Enter to commit. Unselected changes stay uncommitted. A member's requested commit includes only the files selected when it was requested.
- **看得到差异 / See the diffs** —— 提交历史里选中提交的文件、文件标签的对比模式里点改动的文件，都显示该文件的差异，可切回看完整内容。手动 Git 操作后改动标签自动刷新。
  In the commit history, picking a changed file shows its diff; in the files tab's compare mode, picking a changed file does too, with a switch back to the full file. The changes tab refreshes after manual Git actions.
- **推送说明更清楚 / Clearer push** —— 推送前说明会推送几个提交到哪个远程分支；无上游时说明会新建远程分支；被拒时提示先拉取。切换分支在工作区干净时不再弹确认框。
  The push dialog says how many commits go where, and that a new remote branch will be created when there is no upstream. A rejected push asks you to pull first. Switching branches no longer asks for confirmation when the work tree is clean.
- **Git 操作进群 / Git in the group** —— 切换分支、拉取、提交、推送成功后，群里会出现一条事件，成员申请经主人批准的会注明批准人。
  After a successful switch, pull, commit or push, the group gets an event; a member's approved request names the approver.
- **定时任务独立会话 / Scheduled tasks in their own session** —— 定时任务每次在新会话中运行，不续接群内会话，也不改变群内上下文；成员手动 @ Bot 仍续接原会话。
  Scheduled tasks run in a new session each time, without resuming the group's session or changing its context. A manual @ still resumes the session.
- **整目录发布客户端 / Publish a release directory** —— `client_release_publish` 的 `dir` 参数可一次上传 `dist/<版本>/` 中的全部产物，审批卡片列出将发布的文件，只需审批一次；说明文件最后上传。
  The `dir` argument of `client_release_publish` uploads every artifact of a `dist/<version>/` directory; the approval card lists the files, and one approval covers them all. The release notes file goes last.

## 升级须知 / Upgrade notes

- 按文件提交、查看差异、手动刷新需要 Bot 所在机器的 `gg` / 桌面端升级到 v0.3.7；旧版本上这些操作会提示「客户端版本过旧」。切换分支、拉取、整体提交与推送仍需要 v0.3.6 及以上。
  Committing selected files, viewing diffs and refreshing need `gg` / the desktop app on v0.3.7 on the Bot's machine; older ones say the client is too old. Switching, pulling, committing everything and pushing still work from v0.3.6.
- v0.2.0 及以上的 `gg` 与桌面端会自动更新到本版本。
  `gg` and desktop apps from v0.2.0 on update themselves to this release.
