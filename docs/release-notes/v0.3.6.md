# v0.3.6

这一版给群里带来 **手动 Git 操作**：在 Git 状态条上直接切换分支、拉取、提交、推送，查看提交历史，按分支或提交查看与对比文件树；客户端更新提示也会显示具体的更新说明。

This release brings **manual Git** to groups: switch branches, pull, commit and push right from the Git bar, browse commit history, and view or compare file trees at any branch or commit. Client update prompts now show the actual release notes.

## 亮点 / Highlights

- **手动 Git 操作 / Manual Git** —— 绑定了仓库的分区模式群里，点 Git 状态条的分支名可搜索、切换本地或远程分支，并查看远程仓库；一个 Git 菜单汇集查看改动、拉取（只快进）、提交（用 Bot 的提交身份）、推送（从不强推，推送受保护的基准分支需再次确认）、提交历史与操作记录。Bot 主人直接执行；其他成员发起时进入「待审批」，由主人批准后执行，30 分钟过期。Bot 运行中（含同目录的其他 Bot）不能执行写操作。
  In partition groups with a repo, click a branch name in the Git bar to search and switch local or remote branches and see the remotes; one Git menu holds view changes, pull (fast-forward only), commit (as the Bot's commit identity), push (never forced; pushing the protected base branch asks again) plus history and activity. The Bot's owner runs them at once; other members' requests wait for the owner's approval and expire after 30 minutes. Writes are refused while the Bot, or another Bot in the same directory, is running.
- **提交历史与版本对比 / History and compare** —— 工作台新增「提交历史」，可切换分支、分页、点开提交看改了哪些文件；文件标签页可按任意分支或提交查看，并有「对比」模式标出新增、修改、删除与重命名，不动工作区。
  A "History" tab in the workbench (switch branch, page through, open a commit to see its files); the files tab views any branch or commit and has a "Compare" mode marking added, modified, deleted and renamed files, without touching the work tree.
- **更新说明 / Release notes in updates** —— 「管理后台 → 客户端发布」可上传或在线编辑 `RELEASE_NOTES.md`，桌面端更新提示与 `gg` 检查更新会显示具体说明；Bot 可用 `client_release_notes` 写入说明。
  "Admin → Client releases" takes an uploaded or edited `RELEASE_NOTES.md`; the desktop update prompt and `gg` update checks show it, and Bots can write it with `client_release_notes`.

## 升级须知 / Upgrade notes

- 手动 Git 操作需要 Bot 所在机器的 `gg` / 桌面端升级到 v0.3.6；旧版本机器上点 Git 功能会提示「客户端版本过旧」。
  Manual Git needs `gg` / the desktop app on v0.3.6 on the Bot's machine; on older ones the Git actions say the client is too old.
- v0.2.0 及以上的 `gg` 与桌面端会自动更新到本版本。
  `gg` and desktop apps from v0.2.0 on update themselves to this release.
