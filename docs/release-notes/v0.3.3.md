这一版带来 **Agent 设置**：上下文窗口、输出上限等常用配置不用再手写环境变量，Claude Code 自身的语言、思考、提交署名等也能在本机统一设置、按 Bot 覆盖，并标出每项生效值的来源。另外还有撤回后重新编辑、文件路径可点击、分支到新聊天、飞书单聊 Bot 等改进。

This release brings **Agent settings**: common options such as the context window and output limit no longer need hand-written environment variables, Claude Code's own settings (language, thinking, commit attribution…) can be set per machine and overridden per Bot, and every value shows where it comes from. Also: edit after recall, clickable file paths, branching into a new chat, Feishu direct chats with Bots and more.

## 亮点 / Highlights

- **供应商常用配置 / Provider controls** —— 供应商「高级」改为表单控件：上下文窗口（200K / 256K / 1M / 自定义，按所选模型自动带出）、自动压缩窗口、输出上限、关闭思考参数、关闭实验性 beta、工具搜索、API 超时；单项恢复预设，未改动的值原样保留。
  The provider's Advanced section becomes form controls: context window (200K / 256K / 1M / custom, filled in from the chosen model), auto-compact window, output limit, thinking, experimental betas, tool search and API timeout; reset a single field to the preset, untouched values stay as they are.
- **Agent 设置 / Agent settings** —— 机器页新增「Agent 设置」：语言、扩展思考、提交署名、git 指令、自动记忆、自动压缩、Bash 超时、非必要流量，以及「继承本机 CLI 配置」开关；Bot 可单独覆盖语言、思考与署名。每项标出来源（默认 / 本机 CLI / Agent 设置 / 供应商 / 按模型 / Bot），本机 CLI 会盖过 Bot 的变量会提示。改动在下一轮生效。
  A new Agent settings tab per machine (language, extended thinking, commit attribution, git instructions, auto memory, auto-compact, Bash timeouts, nonessential traffic, and whether to inherit the local CLI config); Bots can override language, thinking and attribution. Each value shows its source, conflicting local CLI variables are flagged, and changes apply from the next turn.
- **可观测 / Visibility** —— 上下文圆环标出自动压缩点；运行详情显示本轮设置来源；`gg agents settings` 命令行管理；环境变量里的密钥打码显示。
  The context ring marks where auto-compaction runs; run details show where the turn's settings came from; `gg agents settings` on the command line; secrets in environment variables are masked.
- **聊天 / Chat** —— 撤回 5 分钟内可「重新编辑」；Bot 回复里的文件路径可点击并按行号打开；从 Bot 回复「分支到新聊天」；引用 Bot 消息不再触发该 Bot。
  Edit a message within 5 minutes of recalling it; file paths in Bot replies open the file at the line; branch a Bot reply into a new chat; quoting a Bot no longer triggers it.
- **会话与搜索 / Conversations & search** —— 会话列表按最新消息排序并显示运行状态；⌘K 可搜会话名；群 Bot 栏「执行位置」面板。
  Conversations sorted by latest message with run status; ⌘K finds conversations by name; an "Execution location" panel in the group's Bot bar.
- **飞书 / Feishu** —— 单聊 Bot 自己的飞书应用即可对话；审批与提问合进运行卡片；可关闭网页消息同步到飞书群。
  Chat with a Bot through its own Feishu app; approvals and questions folded into the run card; web-to-Feishu sync can be turned off.
- **其他 / More** —— `hand_off` 可交给其他群的 Bot；非管理员可只读查看群 MCP / Skill；自装的 Codex、Claude Code 也能一键升级；更少的只读命令审批；绑定新机器按系统推荐下载。
  `hand_off` to Bots in other groups; read-only MCP / Skill view for members; one-click upgrades for self-installed Codex and Claude Code; fewer approvals for read-only commands; OS-aware client download when binding a machine.

## 升级须知 / Upgrade notes

- Agent 设置需要服务端、`gg` 与网页都升级到 v0.3.3；服务端启动时自动执行数据库迁移。已有供应商的环境变量无需迁移，打开编辑页即按控件显示。
  Agent settings need the server, `gg` and the web app on v0.3.3; the server applies database migrations on start. Existing provider variables need no migration and show up as controls in the editor.
- `ANTHROPIC_SMALL_FAST_MODEL` 已被 Claude Code 废弃，编辑页提供「改用 Haiku 映射」。
  `ANTHROPIC_SMALL_FAST_MODEL` is deprecated by Claude Code; the editor offers to move it to the Haiku mapping.
- v0.2.0 及以上的 `gg` 与桌面端会自动更新到本版本。
  `gg` and desktop apps from v0.2.0 on update themselves to this release.
