# v0.3.8

这一版把子仓库与主仓库的分支统一收进一个「仓库 → 分支」树，并把执行位置、Git 操作和文件入口合并成一个工作区菜单。多仓项目的分支查看、切换和拉取都更集中，重复信息更少。

This release brings subrepositories and the main repository into one repository → branch tree, and combines location, Git actions, and files in a single workspace menu. Working across multi-repository projects is more compact, with less duplicated information.

## 亮点 / Highlights

- **一个分支树看全部仓库 / All repositories in one branch tree** —— 主仓库、子模块、嵌套仓库和附加目录仓库显示为「仓库 → 分支」两级结构。当前分支直接标出，有改动时显示提示。
  The main repository, submodules, nested repositories, and repositories in extra folders appear in one repository → branch structure. The current branch is marked, with a change hint when needed.
- **子仓库也能切换和拉取 / Switch and pull subrepositories too** —— 仓库树中可选择任意本地或远程分支；远程分支可切换到本地跟踪分支。落后远程时可直接拉取，错误和越界仓库会被明确拒绝。
  The tree lets you pick local or remote branches, switch remote branches to local tracking branches, and pull when behind. Invalid or out-of-scope repositories are refused explicitly.
- **工作区菜单更简洁 / A cleaner workspace menu** —— 机器、目录、仓库和基准分支放在菜单顶部；查看改动、浏览文件、拉取、提交、推送、历史和操作记录集中在一处。托管目录 / 本机目录的说明移入菜单，不再占用工具条。
  Machine, directory, repository, and base branch sit at the top of the workspace menu. Changes, files, pull, commit, push, history, and operation records live together. The managed/local workspace label moves into the menu instead of using toolbar space.
- **更稳妥的仓库边界 / Safer repository boundaries** —— `git.refs` 和 `git.action` 增加可选的 `repo` 参数；daemon 只允许工作区内的子仓库、嵌套仓库或附加目录中的仓库，越界路径会被拒绝。
  `git.refs` and `git.action` gain an optional `repo` parameter. The daemon accepts only subrepositories or nested repositories inside the workspace and repositories in extra folders; paths outside those boundaries are rejected.

## 升级须知 / Upgrade notes

- 子仓库分支查看、切换和拉取需要 Bot 所在机器的 `gg` / 桌面端升级到 v0.3.8。旧版 daemon 上，网页会提示「客户端版本过旧」。
  Viewing, switching, and pulling subrepository branches requires `gg` or the desktop app on v0.3.8 on the Bot's machine. Older daemons show the client-is-too-old notice.
- 本次新增 `gitRepos` 能力标识；旧客户端、旧服务和旧操作记录保持兼容。提交、推送仍作用于主仓库。
  This release adds the `gitRepos` capability flag; old clients, old servers, and old operation records remain compatible. Commit and push still target the main repository.
- v0.3.7 的按文件提交、差异查看与手动刷新保持不变。已安装 v0.2.0 及以上客户端会自动更新。
  The v0.3.7 selected-file commits, diffs, and manual refresh are unchanged. Clients on v0.2.0 and later update automatically.
