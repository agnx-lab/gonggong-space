# v0.3.9

这一版修复了后台任务跑完后 Bot 接着干的活丢失的问题，并让 Bot 能在对话里直接发起插件创作。

This release fixes lost work when a Bot continues after a background task, and lets Bots start plugin creations right from the chat.

## 亮点 / Highlights

- **后台任务跑完后接着干，不再丢失 / Work after a background task is no longer lost** —— Bot 把命令放到后台跑、说「跑完后再做」时，这一轮会先结束；后台任务跑完、Bot 自己接着干时，会单独开一轮运行，卡片标「后台任务完成后继续」，回复、审批、改动和用量都正常记录。以前这部分回复会被丢掉，要审批的操作会被自动拒绝。
  When a Bot runs a command in the background and says it will continue once it finishes, the run ends first; when the Bot continues on its own, a new run labelled "Continued after background task" records its reply, approvals, changes and usage. Previously this output was dropped and actions needing approval were refused.
- **后台命令不再被提前清理 / Background commands are no longer cut short** —— 有后台任务在跑时，机器不再因空闲回收 agent 进程。
  The machine no longer recycles an idle agent process while background tasks are running.
- **对话里发起创作 / Start creations from the chat** —— 群里启用插件后，Bot 可用 `plugin_catalog` 查模板与设计系统，用 `creation_propose` 发「创作确认卡」，成员点「开始」、改参数或「不用了」。
  With plugins enabled in a group, Bots can look up templates and design systems with `plugin_catalog` and post a creation proposal with `creation_propose`; members start it, edit it or dismiss it.

## 升级须知 / Upgrade notes

- 两项都需要 Bot 所在机器的 `gg` / 桌面端升级到 v0.3.9，服务端需同步更新。旧版客户端行为与之前相同。
  Both need `gg` or the desktop app on v0.3.9 on the Bot's machine, together with an updated server. Older clients behave as before.
- 已安装 v0.2.0 及以上客户端会自动更新。
  Clients on v0.2.0 and later update automatically.
