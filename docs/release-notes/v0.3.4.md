这一版让 **上下文与压缩** 变得准确可见，并新增 **群知识库**：圆环按 Agent 实际的压缩点提示，压缩前后在群里一目了然；群里需要所有 Bot 记住的事实可以写进知识库，Bot 每次运行都能读到、也会自己维护。另外运行详情大幅增强，群聊上下文改按 token 预算附带。

This release makes **context and compaction** accurate and visible, and adds a **group knowledge base**: the ring warns at the point where the agent really compacts, compactions show up in the group, and facts every Bot of a group should remember live in a knowledge base that Bots read on every run and help maintain. Run details are much richer, and group context is attached within a token budget.

## 亮点 / Highlights

- **上下文与压缩 / Context & compaction** —— 圆环按 Claude Code 实际压缩点（窗口 − 输出预留 − 13k）标记与变色，未配置压缩窗口也能显示；关闭自动压缩时改为提示 Agent 会停下的位置。压缩开始与结束会上报：运行卡片显示「正在压缩上下文」，群里发「已自动压缩上下文 167k → 12k」，运行过程可展开压缩摘要。手动压缩可填写保留重点。上下文占用不再被当成用量统计；会话重置后不再显示旧占用。
  The ring marks and colours by where Claude Code really compacts (window − output reserve − 13k), even without a configured window; with auto-compaction off it shows where the agent will stop. Compactions are reported: the run card shows "compacting", the group gets "auto-compacted 167k → 12k", and the run process holds the summary. Manual compaction takes instructions. Occupancy no longer counts as usage, and a reset session no longer shows a stale ring.
- **桌面端占用圆环 / Context ring on desktop** —— 工作区表新增「上下文」列，概览「正在运行」行显示圆环。
  A Context column in Workspaces and rings on running rows in Overview.
- **群聊上下文按 token 预算 / Token-budgeted group context** —— 每轮附带的群聊上下文默认 8000 token、会话恢复失败补送 16000 token，不再限条数；超长消息截断并提示 Bot 用 `list_messages` 取全文。
  Group context is attached within 8000 tokens per turn (16000 when a session cannot be resumed) instead of a message count; overlong messages are clipped with a pointer to `list_messages`.
- **群知识库 / Group knowledge base** —— 群设置侧栏「知识库」：markdown 条目、标签、搜索、版本历史对比与回滚，管理员置顶与删除，消息菜单「存入知识库」。Bot 新会话读到置顶全文与条目目录、续接会话只读变化，并可用 `kb_list` / `kb_get` / `kb_search` / `kb_create` / `kb_update` / `kb_delete` 维护（改动标注 Bot）。
  A Knowledge base in the group side panel: markdown entries, tags, search, version history with diff and rollback, pinning and deletion by admins, and "Save to knowledge base" on messages. New sessions get pinned entries and an index, resumed ones only the changes; Bots maintain it with the `kb_*` tools, marked as Bot edits.
- **运行详情 / Run details** —— 过程每行带时间点，可按失败/需处理/命令筛选，命令输出可搜索、复制；待处理的审批与提问可在详情里直接处理；失败、中断等原因横幅（桌面端同样）与「重新运行」。
  Timestamps on every step, filters for failures / pending / commands, searchable and copyable output; approve and answer in place; banners explaining failures (desktop too) and Re-run.
- **其他 / More** —— 定时任务可按候选 Bot 选模型与思考程度；群已读时清掉对应「被 @」通知；搜索、未读计数、实时推送、daemon 等多项性能优化。
  Per-Bot model and effort for scheduled tasks; reading a group clears its mention notifications; faster search, unread counts, realtime pushes and daemon.

## 升级须知 / Upgrade notes

- 服务端启动时自动执行数据库迁移（新增群知识库两张表）。系统参数「每轮随消息附带的群聊上下文」「会话恢复失败时补送群消息数」改为 token 上限，旧的条数设置不再生效。

  Compaction points and reports need `gg` / the desktop app on v0.3.4.
- v0.2.0 及以上的 `gg` 与桌面端会自动更新到本版本。
  `gg` and desktop apps from v0.2.0 on update themselves to this release.
