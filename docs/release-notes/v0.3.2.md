这一版让 **Bot 自己管理 MCP 与 Skill**，并把桌面端更新改为 **私服优先**：服务器发布了桌面端更新包时，桌面端直接从服务器升级，不再绕道 GitHub。另外带来飞书深度联动、会话列表右键菜单和多目录工作区。

This release lets **Bots manage MCP servers and Skills themselves** and makes desktop updates **server-first**: once your server publishes a desktop update package, the desktop app upgrades from it instead of GitHub. Also new: deeper Feishu integration, a context menu for conversations and multi-folder workspaces.

## 亮点 / Highlights

- **桌面端私服优先更新 / Server-first desktop updates** —— 桌面端先向已绑定的服务器检查更新，服务器在「管理后台 → 客户端发布」（或 Bot 的 `client_release_publish`）发布了本平台的更新包与签名（macOS `Gonggong_<版本>_<架构>.app.tar.gz` + `.sig`，Windows `Gonggong_<版本>_x64-setup.exe` + `.sig`）就从服务器下载；没有发布时照旧检查 GitHub。后台新增「桌面端自动更新」列，标出各平台是否就绪。
  The desktop app asks its server first: once the server publishes this platform's update package and signature (macOS `Gonggong_<v>_<arch>.app.tar.gz` + `.sig`, Windows `Gonggong_<v>_x64-setup.exe` + `.sig`) under Admin → Client releases (or through a Bot's `client_release_publish`), it downloads from there; otherwise it checks GitHub as before. A new "Desktop auto update" column shows which platforms are ready.
- **Bot 管理 MCP / Bots manage MCP** —— 内置工具 `mcp_list` / `mcp_create` / `mcp_update` / `mcp_toggle` 等管理平台、团队、群三层 MCP，按发起人权限校验；密钥一律写占位符，由发起人在「填写密钥」卡片里填写，不经过 Agent、不进消息和日志。
  Built-in tools manage platform, team and group MCP servers under the requester's permissions; secrets are placeholders filled in by the requester on a secret card, never seen by the agent or written to messages and logs.
- **群可关闭继承的 Skill 与 MCP / Per-group opt-out** —— 群设置里单独关掉从团队、平台继承来的 Skill 和 MCP，其他群不受影响。
  Groups can switch off Skills and MCP servers inherited from the team or platform without affecting other groups.
- **飞书 / Feishu** —— Bot 可往绑定的飞书群发自定义卡片（`feishu_send_card`）；从已有飞书群一键创建共工群，或为共工群一键创建飞书群；同步飞书群成员；审批、提问等飞书通知。
  Bots post custom cards to the bound Feishu group; create a Gonggong group from a Feishu group or the other way round; sync members; Feishu notifications for approvals and questions.
- **会话列表 / Conversations** —— 右键（手机长按）置顶、免打扰、标记、完成；被 @ 时单独提醒；聊天顶栏可点开群设置或群信息；悬停名片一键 @。
  Right-click (long-press on phones) to pin, mute, mark or complete; mention alerts; clickable chat header; @ from hover cards.
- **工作区 / Workspaces** —— Bot 可同时在多个附加目录工作；Bot 入群不再静默克隆，主人确认后再准备工作区；群可解绑仓库、可禁止直推基准分支。
  Bots work in extra folders too; joining a group no longer clones silently but waits for the owner; groups can unbind repos and block direct pushes to the base branch.
- **用本地应用打开 / Open with** —— 文件工作区右上角一键让 Bot 所在机器用访达、Cursor、IntelliJ IDEA、VS Code、终端等打开工作区。
  One click in the files workspace opens it on the Bot's machine in Finder, Cursor, IntelliJ IDEA, VS Code or a terminal.
- **其他 / More** —— 头像上传与裁剪、申请共享他人的 Bot、管理后台会话统计、Codex 启动前检查 CLI、手机端输入框与布局修复。
  Avatar upload and crop, requesting access to others' Bots, conversation stats in the admin console, a Codex CLI check before start, mobile composer and layout fixes.

## 升级须知 / Upgrade notes

- 私服优先更新需要服务端与桌面端都升级到 v0.3.2；旧版桌面端会先从 GitHub 更新到本版本，之后改为优先检查服务器。服务端启动时自动执行数据库迁移。
  Server-first updates need both the server and the desktop app on v0.3.2; older desktop apps reach this release through GitHub and ask the server first from then on. The server applies database migrations on start.
- 要让成员从服务器更新桌面端，把 `dist/0.3.2/` 里的 `Gonggong_*.app.tar.gz`、`.sig` 与 Windows 安装包的 `.sig` 一并上传到「客户端发布」。
  For members to update the desktop app from your server, also upload `Gonggong_*.app.tar.gz`, the `.sig` files and the Windows installer's `.sig` from `dist/0.3.2/` under Client releases.
- v0.2.0 及以上的 `gg` 与桌面端会自动更新到本版本。
  `gg` and desktop apps from v0.2.0 on update themselves to this release.
