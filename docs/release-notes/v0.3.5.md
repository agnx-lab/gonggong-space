# v0.3.5

这一版带来 **插件** 与 **密钥管理**：群里启用插件后可从「✦ 创作」面板把创作任务交给 Bot；密钥按平台/团队/群/个人分层管理，运行时只以环境变量注入 Bot。Agent 可选模型也随配置实时更新。

This release brings **plugins** and **secrets**: once a group enables a plugin, the "✦ Create" panel hands creative work to a Bot; secrets are managed per platform, team, group and person and reach Bots only as environment variables at run time. The models an agent offers now follow its config too.

## 亮点 / Highlights

- **插件 / Plugins** —— 配置中心、团队与群设置新增「插件」页，上传文件夹或 zip（同名即新版本），群管理员按插件启用，并按 Bot 显示可用性与原因；启用后输入框出现「✦ 创作」，4 步面板选模板、设计系统与参数后交给 Bot，时间线出现创作请求卡片。内置官方插件「网页原型」。由系统参数「插件」总开关控制，默认关闭。
  A "Plugins" page in the config center, team and group settings: upload a folder or zip (same name = new version); group admins enable plugins and see per-Bot availability. With a plugin enabled, "✦ Create" opens a 4-step panel (template, design system, parameters, Bot) and posts a creation card. Ships with the official "Web prototype" plugin. Behind the "Plugins" system switch, off by default.
- **密钥管理 / Secrets** —— 平台、团队、群三层定义密钥，成员可在「我的密钥」填个人值（默认不允许他人机器上的 Bot 使用）；运行时只作为环境变量交给 Agent，不落盘，运行输出、审批、diff 中按值打码；MCP 的 env / headers 改用 `${secret:NAME}` 引用，旧明文自动迁移；Bot 缺密钥时发「填写密钥」卡片。
  Secrets defined per platform, team and group, plus personal values under "My secrets" (not used by Bots on others' machines unless allowed); injected only as environment variables, never written to disk, and masked in output, approvals and diffs; MCP env / headers reference `${secret:NAME}`, with old plaintext migrated; Bots ask for missing ones with a "Fill in secret" card.
- **待处理区 / Pending dock** —— 本群待审批和待回答的提问固定在输入框上方，可直接批准/拒绝或回答、「定位」到原卡片，只显示自己能处理的。
  Pending approvals and questions sit above the composer, to approve, deny, answer or jump to; only the ones you can act on.
- **进度卡片 / Progress cards** —— Bot 可发一张原地更新的进度卡（阶段、状态、百分比、链接），飞书同步更新。
  Bots post a progress card that updates in place (stages, status, percentage, links), mirrored to Feishu.

- **刷新模型 / Refresh models** —— Bot 设置页的模型选择旁新增「刷新模型」，由 Bot 所在机器重新探测 agent 的可选模型，成功后提示数量，失败保留原列表并给出原因。仅 Bot 主人、在线且 `gg` / 桌面端已升级到 v0.3.5 的机器上可用；使用第三方供应商时由供应商配置决定模型，不显示。
  A "Refresh models" button sits beside the model picker: the Bot's machine probes the agent again and the count is shown on success; on failure the previous list is kept and the reason is shown. Available to the Bot's owner when the machine is online and on v0.3.5; with a third-party provider the models come from its configuration and the button is hidden.
- **配置变化自动生效 / Config changes apply automatically** —— 机器每分钟检查一次 Codex（`~/.codex/config.toml`，或 `CODEX_HOME` 指向的目录）与 Claude Code（`~/.claude/settings.json`）的配置，内容变化后重新探测，新增或删除的模型在网页上几秒内更新。
  Every minute the machine checks the Codex (`~/.codex/config.toml`, or under `CODEX_HOME`) and Claude Code (`~/.claude/settings.json`) configs; when their content changes it re-probes, so added or removed models show up in the web within seconds.

- **其他 / Also** —— 图片预览可在同一条消息的多张图间切换（方向键、按钮、手机滑动）并修复工具栏按钮看不见；手机端 @ 候选与「Git 与仓库」弹窗不再溢出；同名前缀 Bot 的 @ 解析修正。
  Image preview steps through a message's images (arrow keys, buttons, swipe) with visible toolbar buttons; mobile @ suggestions and the "Git & repos" dialog no longer overflow; @ mentions of Bots sharing a name prefix resolve correctly.

## 升级须知 / Upgrade notes

- 「刷新模型」需要 `gg` / 桌面端升级到 v0.3.5；更早的版本仍会在配置变化时按版本号重新探测，但网页上没有刷新按钮。
  "Refresh models" needs `gg` / the desktop app on v0.3.5; older versions still re-probe when their version changes, but the web shows no refresh button.
- 插件与密钥注入需要 `gg` / 桌面端 v0.3.5；旧版本机器上的 Bot 在插件页显示为不可用。
  Plugins and secret injection need `gg` / the desktop app on v0.3.5; Bots on older machines show as unavailable for plugins.
- v0.2.0 及以上的 `gg` 与桌面端会自动更新到本版本。
  `gg` and desktop apps from v0.2.0 on update themselves to this release.
