# v0.3.5

这一版让 **Agent 可选模型** 随配置实时更新：编辑 Codex 或 Claude Code 的用户配置后，机器会自动重新探测；网页上还可以在 Bot 设置里点「刷新模型」立即重新探测。

This release keeps **the models an agent offers** up to date: after editing the Codex or Claude Code user config, the machine re-probes on its own; in Bot settings, "Refresh models" re-probes right away.

## 亮点 / Highlights

- **刷新模型 / Refresh models** —— Bot 设置页的模型选择旁新增「刷新模型」，由 Bot 所在机器重新探测 agent 的可选模型，成功后提示数量，失败保留原列表并给出原因。仅 Bot 主人、在线且 `gg` / 桌面端已升级到 v0.3.5 的机器上可用；使用第三方供应商时由供应商配置决定模型，不显示。
  A "Refresh models" button sits beside the model picker: the Bot's machine probes the agent again and the count is shown on success; on failure the previous list is kept and the reason is shown. Available to the Bot's owner when the machine is online and on v0.3.5; with a third-party provider the models come from its configuration and the button is hidden.
- **配置变化自动生效 / Config changes apply automatically** —— 机器每分钟检查一次 Codex（`~/.codex/config.toml`，或 `CODEX_HOME` 指向的目录）与 Claude Code（`~/.claude/settings.json`）的配置，内容变化后重新探测，新增或删除的模型在网页上几秒内更新。
  Every minute the machine checks the Codex (`~/.codex/config.toml`, or under `CODEX_HOME`) and Claude Code (`~/.claude/settings.json`) configs; when their content changes it re-probes, so added or removed models show up in the web within seconds.

## 升级须知 / Upgrade notes

- 「刷新模型」需要 `gg` / 桌面端升级到 v0.3.5；更早的版本仍会在配置变化时按版本号重新探测，但网页上没有刷新按钮。
  "Refresh models" needs `gg` / the desktop app on v0.3.5; older versions still re-probe when their version changes, but the web shows no refresh button.
- v0.2.0 及以上的 `gg` 与桌面端会自动更新到本版本。
  `gg` and desktop apps from v0.2.0 on update themselves to this release.
